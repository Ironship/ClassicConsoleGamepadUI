# AI Instructions

These instructions apply to the entire ClassicGamepad repository.

## Strict Rule: No Automated Test Generation

**DO NOT create, generate, modify, or extend automated tests unless I explicitly request them.**

This is a strict, persistent rule that applies to every coding task.

- Never create new test files.
- Never add test cases to existing test files.
- Never generate tests as part of implementing features, fixing bugs, or refactoring code.
- This includes unit tests, integration tests, smoke tests, mock harnesses, and assert-based self-tests added for verification.
- Never proactively suggest writing tests.
- Do not interpret requests such as "implement", "fix", "refactor", "verify", or "make sure it works" as permission to write tests.
- Do not create tests even when doing so would normally be considered a best practice or required by a skill.
- You may run existing tests to verify changes, but must not modify or add tests.
- Focus on production code and the specific changes requested.

**Exception:** You may write or modify tests ONLY when I explicitly ask you to write or modify tests.

**Priority:** Treat this rule as a permanent project-level instruction. Do not override it based on coding conventions, perceived best practices, or autonomous development workflows.
